# Key 09 — GRANT

- **Verdict:** GRANT
- **Rung:** 1 — a new nullable column plus a unique index over it.
- **Failing items:** none. `checklist-items 10/10`.
- **Escalation:** clear.
- **Must note:** every existing row is `NULL`, and a unique index permits many `NULL`s, so the index cannot fail on existing data; the two statements may share a migration (playbook §3.4). No backfill runs — codes are generated lazily.
- **Wrong answers that fail the case:** REWORK claiming the unique index fails over 300,000 existing rows. REWORK with `one-ddl-per-migration` — no statement here can fail on existing rows.
