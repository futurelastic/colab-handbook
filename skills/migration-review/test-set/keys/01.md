# Key 01 — GRANT

- **Verdict:** GRANT
- **Rung:** 0 — a new table; no existing row is read or rewritten.
- **Failing items:** none. `checklist-items 10/10`.
- **Escalation:** clear (`data-loss-rule`).
- **The record must carry:** `--verdict approve --checklist pass --checklist-items 10/10 --escalation data-loss-rule --escalation-result clear --ci-roundtrip pass` and the reviewed HEAD.
- **Wrong answers that fail the case:** any REWORK or ESCALATE. Raising the foreign key as a risk "over existing rows" misreads it: the child table is new and empty.
- **Why:** new table, `down` mirrors `up`, old code never touches it, the parent table is tiny, and the round-trip passed on the deploy engine with the parent seeded.
